====================================================
3D CAR SHOP
====================================================

DESCRIPTION
-----------
3D Car Shop is a front-end car shopping website that displays
interactive 3D car models (embedded from Sketchfab) together with
prices, add-to-cart / buy-now buttons, and a cart section with a
running total.

FEATURES
--------
- Hero section with an embedded 3D "Cyberpunk Car" model and a
  "Shop Now" button
- "Our Selection Of Cars" catalog of 12 cars, each shown as an
  interactive Sketchfab 3D model with its name and price
- "add to cart" and "buy now" buttons on every product card
- Cart icon in the page corner with an item counter
- "Your Cart" section with "Products Bought" and "Your Total Is"
- Navigation bar: Home, Cars, Shop, About Us, Contact
- Custom fonts (Audiowide, Chakra Petch, Oxanium) and Font Awesome icons

INSTALLATION / SETUP
--------------------
No build step or package installation is required.

1. Clone the repository:
   git clone https://github.com/adelmhmd77/3d-Car-Shop.git

2. Open the project folder:
   cd 3d-Car-Shop

3. Open index.html in your web browser.

Note: An internet connection is needed, because the 3D models,
fonts, and icons are loaded from external services (Sketchfab,
Google Fonts, cdnjs).

USAGE
-----
1. Open the live website or the local index.html file.
2. Browse the cars in "Our Selection Of Cars" and rotate/inspect
   each 3D model.
3. Click "add to cart" on a car to add it to your cart.
4. Scroll to "Your Cart" to see the products and the total.
